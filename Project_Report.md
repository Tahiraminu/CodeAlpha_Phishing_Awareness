# CodeAlpha Cybersecurity Internship — Task 2
## Phishing Awareness Training

### 1. Project Overview
This project is an awareness-training presentation designed to help users understand phishing attacks and make safer decisions when handling suspicious digital communications.

### 2. Objectives
- Explain phishing and common phishing categories.
- Identify warning signs of suspicious messages.
- Explain social engineering tactics.
- Share practical prevention and incident-response steps.
- Reinforce learning through an interactive quiz.

### 3. Methodology
The training content was organized into a slide-based module covering definitions, phishing types, warning signs, an illustrative email scenario, social engineering, prevention, incident response, and a quiz with answer explanations.

### 4. Tools
- Microsoft PowerPoint or compatible presentation software.

### 5. Outcome
The presentation provides a basic learning resource for users to recognize suspicious messages and take safer actions. The quiz provides a simple way to reinforce concepts.

### 6. Conclusion
Phishing relies on deception and manipulation. Awareness, careful verification, multifactor authentication, reporting, and prompt incident response help reduce risk.
